# LutaML Website

[![Deploy Pages](https://github.com/lutaml/lutaml.github.io/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/lutaml/lutaml.github.io/actions/workflows/deploy-pages.yml)

This is the source for [lutaml.org](https://www.lutaml.org), built with [VitePress](https://vitepress.dev/).

## Development

```bash
npm install     # Install dependencies
npm run dev     # Start development server
npm run build   # Build for production
npm run preview # Preview production build
```

## Adding Blog Posts

1. Create a new `.md` file in `blog/` with frontmatter
2. Add an entry to `blog/index.md`
